Lite:
    npm install  
    npx expo install   
    npx expo start

Development:
    npx eas-cli@latest login
    npx expo-doctor  
    npx eas-cli@latest build:configure
    npx eas-cli@latest build --platform android --profile development
    npx expo start --dev-client

Production:
    npx expo-doctor  
    eas build:configure
    eas build --platform android --profile production
